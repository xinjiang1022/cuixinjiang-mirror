Halo博客 Meilisearch

halo博客更改原始搜索为Meilisearch服务

Administrator 字数: 14614 阅读耗时: 36 分钟 2026/09/03 博客独享 热度: 17 评论: 0

一、需求背景

Halo 默认使用内置的 Lucene 搜索引擎，当内容量增大时，搜索速度和相关性可能下降。Meilisearch 是一款开源的轻量级搜索引擎，具有以下优势：

  • 搜索速度快：毫秒级响应

  • 相关性高：支持模糊搜索、前缀搜索、中文分词

  • 开箱即用：配置简单，API 友好

  • 资源占用低：适合个人博客和小型站点

本教程将指导您在现有 Halo + PostgreSQL 的 Compose 编排中，无缝加入 Meilisearch 服务。

二、环境准备

2.1 确认现有环境

在开始之前，请确认您已经拥有以下环境：

  • 飞牛 NAS 或 Linux 服务器，已安装 Docker 和 Docker Compose

  • 已部署 Halo 服务，使用 PostgreSQL 数据库

  • 现有的 docker-compose.yml 文件内容如下（参考）：

services:
  halo:
    image: registry.fit2cloud.com/halo/halo:2.26.1
    container_name: halo
    restart: unless-stopped
    depends_on:
      halodb:
        condition: service_healthy
    networks:
       - trim-default
    volumes:
      - /var/apps/docker-halo/var/halo2:/root/.halo2
    ports:
      - "28090:8090"
    ...
  halodb:
    image: registry.fnnas.com/fnapp/postgres:15.4
    ...
networks:
  trim-default:
    external: true

2.2 创建数据目录

在宿主机上创建 Meilisearch 数据持久化目录：

sudo mkdir -p /var/apps/docker-halo/var/meilisearch_data
sudo chown -R 1000:1000 /var/apps/docker-halo/var/meilisearch_data

说明：Meilisearch 容器内运行的用户 UID 为 1000，需要确保该目录可被写入。

三、修改 Docker Compose 配置

3.1 完整配置文件

在现有的 services 部分添加 Meilisearch 服务，修改后的完整 docker-compose.yml 如下：

services:
  halo:
    image: registry.fit2cloud.com/halo/halo:2.26.1
    container_name: halo
    restart: unless-stopped
    depends_on:
      halodb:
        condition: service_healthy
    networks:
       - trim-default
    volumes:
      - /var/apps/docker-halo/var/halo2:/root/.halo2
    ports:
      - "28090:8090"
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8090/actuator/health/readiness"]
      interval: 30s
      timeout: 5s
      retries: 5
      start_period: 30s
    environment:
      - JVM_OPTS=-Xmx256m -Xms256m
    command:
      - --spring.r2dbc.url=r2dbc:pool:postgresql://halodb/halo
      - --spring.r2dbc.username=halo
      - --spring.r2dbc.password=openpostgresql
      - --spring.sql.init.platform=postgresql
      - --halo.external-url=http://localhost:8090/

  halodb:
    image: registry.fnnas.com/fnapp/postgres:15.4
    restart: unless-stopped
    networks:
      - trim-default
    volumes:
      - /var/apps/docker-halo/var/data:/var/lib/postgresql/data
    healthcheck:
      test: [ "CMD", "pg_isready" ]
      interval: 10s
      timeout: 5s
      retries: 5
    environment:
      - POSTGRES_PASSWORD=openpostgresql
      - POSTGRES_USER=halo
      - POSTGRES_DB=halo
      - PGUSER=halo

  # ========== 新增 Meilisearch 服务 ==========
  meilisearch:
    image: getmeili/meilisearch:v1.15
    container_name: meilisearch
    restart: unless-stopped
    networks:
      - trim-default
    ports:
      - "7700:7700"
    volumes:
      - /var/apps/docker-halo/var/meilisearch_data:/meili_data
    environment:
      - MEILI_ENV=production
      - MEILI_MASTER_KEY=请替换为强密钥

networks:
  trim-default:
    external: true

3.2 配置项详解

配置项

说明

image: getmeili/meilisearch:v1.15

指定镜像版本，建议固定版本号避免升级带来兼容性问题

networks: - trim-default

加入 Halo 所在的网络，实现容器间通信

ports: "7700:7700"

映射端口到宿主机，方便外部调试（非必须，若仅内部通信可移除）

volumes

挂载数据目录，保证索引数据持久化

MEILI_ENV=production

设置为生产模式，启用安全特性

MEILI_MASTER_KEY

必须修改，设置为强密码（至少16字节）

3.3 生成强密钥

执行以下命令生成安全的 Master Key：

openssl rand -base64 32

将生成的字符串替换到 MEILI_MASTER_KEY= 后面，例如：

- MEILI_MASTER_KEY=Kx9mP2nQ5sV8wZ3jL7fR1tY4cA6dE0bH

⚠️ 重要：Master Key 是 Meilisearch 的管理密钥，请妥善保管，切勿泄露或使用弱密码（密码长度必须大于16位，否则设置不成功）。

四、部署与启动服务

4.1 启动所有服务

在 docker-compose.yml 文件所在目录执行：

docker-compose up -d

4.2 检查服务状态

查看所有容器是否正常运行：

docker-compose ps

应显示三个容器状态均为 Up（或 healthy）：

NAME           STATUS
halo           Up (healthy)
halodb         Up (healthy)
meilisearch    Up

4.3 查看 Meilisearch 日志

确认 Meilisearch 启动成功，无报错信息：

docker logs meilisearch

正常启动的日志末尾应显示类似：

Meilisearch is running on http://0.0.0.0:7700
The server is now ready to receive requests

五、安装与配置 Halo 插件

5.1 安装 Meilisearch 插件

  1. 登录 Halo 后台管理界面

  2. 进入 应用 → 应用市场

  3. 在搜索框输入 Meilisearch

  4. 找到官方插件，点击 安装

如果应用市场中找不到，可以进入 应用 → 插件 → 上传，手动上传插件 JAR 包。

5.2 配置插件

  1. 安装完成后，进入 应用 → 已安装

  2. 找到 Meilisearch 插件，点击 设置

  3. 填写以下配置项：

配置项

填写内容

说明

Meilisearch 服务地址

http://meilisearch:7700

通过内部网络访问，服务名即容器名

Master Key

您在 Compose 中设置的密钥

必须与配置文件中的 MEILI_MASTER_KEY 一致

索引名称

halo（默认）

如多个站点共用可自定义

  1. 点击 保存

5.3 启用搜索引擎

  1. 进入 Halo 后台 系统 → 扩展点定义

  2. 在 搜索引擎 下拉框中选择 Meilisearch

  3. 点击 保存

六、验证与测试

6.1 重建索引

  1. 回到 应用 → 已安装 → 点击 Meilisearch 插件

  2. 进入 数据概览 页面

  3. 点击 重建索引 按钮

  4. 等待同步完成，页面会显示索引的数据量

6.2 测试搜索

方法一：前台搜索

  • 在 Halo 站点前台搜索框输入关键词，观察搜索结果是否正常返回

方法二：插件测试

  • 在 Meilisearch 插件的 工具 或 测试搜索 页面直接测试

6.3 访问 Meilisearch 控制台（可选）

在浏览器访问 http://你的服务器IP:7700，可看到 Meilisearch 的 Web 控制台，输入 Master Key 后可查看索引状态、文档数量等统计信息。

七、常见问题排查

7.1 容器一直转圈无法启动

现象：执行 docker-compose up -d 后，Meilisearch 容器状态一直显示 starting 或反复重启。

原因与解决方案：

🔴 原因一：Master Key 长度不足

错误日志示例：

The master key must be at least 16 bytes...

解决方案：

  1. 执行 openssl rand -base64 32 生成强密钥

  2. 更新 docker-compose.yml 中的 MEILI_MASTER_KEY

  3. 重启服务：docker-compose up -d

🔴 原因二：数据卷版本不兼容

错误日志示例：

Your database version (X.X.X) is incompatible with your current engine version (Y.Y.Y)

原因：先前用其他版本运行过，遗留了旧数据，与当前镜像版本不兼容。

解决方案：清除旧数据后重新创建

# 方法一：删除容器和数据卷（推荐）
docker-compose down -v
docker-compose up -d

# 方法二：手动删除数据目录
docker-compose down
sudo rm -rf /var/apps/docker-halo/var/meilisearch_data
docker-compose up -d

⚠️ 注意：删除数据卷会导致所有索引数据丢失，需要重新在 Halo 插件中「重建索引」。

🔴 原因三：宿主机目录权限不足

错误日志示例：

Permission denied: /meili_data

解决方案：

sudo mkdir -p /var/apps/docker-halo/var/meilisearch_data
sudo chown -R 1000:1000 /var/apps/docker-halo/var/meilisearch_data

7.2 Halo 无法连接 Meilisearch

现象：Halo 插件配置保存失败，或重建索引时提示连接超时。

排查步骤：

  1. 检查网络配置：确保 halo 和 meilisearch 都在 trim-default 网络中

    docker network inspect trim-default

    检查输出中是否包含 halo 和 meilisearch 两个容器

  2. 测试容器间连通性：

    docker exec halo curl -f http://meilisearch:7700/health

    应返回 {"status":"available"}

  3. 确认插件地址：填写的是 http://meilisearch:7700，而不是 http://localhost:7700（容器内部 localhost 指向自身）

  4. 检查防火墙：确保服务器防火墙未阻挡 7700 端口的内部通信

7.3 搜索无结果或索引为空

现象：搜索时无任何结果返回。

解决方案：

  1. 进入 Meilisearch 插件 → 数据概览

  2. 确认文档数量 > 0

  3. 若文档数量为 0，点击 重建索引

  4. 重建完成后再次测试搜索

八、安全建议

8.1 Master Key 安全

  • ✅ 使用 openssl rand -base64 32 生成强密钥（至少 32 字符）

  • ✅ 将密钥存储在环境变量或密钥管理系统中，避免明文提交到代码仓库

  • ❌ 不要使用简单密码如 123456、admin、生日等

  • ❌ 不要将 Master Key 暴露在公开的日志或页面中

8.2 端口暴露

  • 如果仅需 Halo 内部访问 Meilisearch，建议移除 ports: - "7700:7700" 配置，避免外部直接访问 API

  • 如需外部访问控制台，建议配合 Nginx 反向代理并启用 HTTPS 和 Basic Auth

8.3 定期备份

Meilisearch 的索引数据存储在 /var/apps/docker-halo/var/meilisearch_data 目录，建议定期备份该目录：

sudo tar -czvf meilisearch_backup_$(date +%Y%m%d).tar.gz /var/apps/docker-halo/var/meilisearch_data
